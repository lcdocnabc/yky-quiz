# 应知应会 · 离线题库复习 App（安卓）

一个**完全离线**的安卓 App：内置 H5 题库，装好即用，不联网、不依赖任何服务器。
用 **GitHub Actions 自动构建 APK**，你只需把代码推到 GitHub，就能下载安装包。

## 核心特性

- **完全离线**：APK 把网页资源（含表格解析库 SheetJS）打包进安装包，运行时零联网（AndroidManifest 未申请任何网络权限）。
- **题库 = 顶层独立单元**：每个**题库**是一个完整、独立的知识体系（如“党员应知应会”“党史题库”），
  它们之间**互不干扰**——题目、答题进度、复习计划全部按题库隔离。可单独导入 / 导出 / 删除某个题库。
- **知识类型 = 库内题型**：在每个题库内部，题目按其**知识类型**区分：`填空` / `单选` / `多选`，
  仅作用于该题库内部。选择题选项用 `|` 分隔，多选答案也用 `|` 分隔。
- **填空题多空**：题干用 `____`（四个下划线）标空位，答案用 `｜`（全角竖线，兼容半角 `|`）分隔多个空的答案。
  **录入时用 `$` 表示空位**（如 `党支部委员会由$人组成`），导入/转换时会自动把 `$` 转成 `____`。
- **手机端即可管理题库**：在 App「题库」页直接改表格、新增、删除题目；可**从手机文件导入 Excel 或 CSV 新建题库**（支持一次导入多个题库），也可**导出 CSV** 备份。
- **答错即显答案**：提交后立刻显示正确答案与解析（填空题逐空标红显示正确空答案）。
- **记忆曲线复习**：错题 10 分钟后重练；答对按第 1/2/4/7 天逐次强化，到第 7 天即标记“已掌握”。统计页跟踪「一周掌握」进度（按题库独立统计）。

## 题库文件格式（导入标准）

**第一列 = 题库名**，可在一个文件里放多个题库（按第一列分组）。
**第二列 = 题型**（`填空`/`单选`/`多选`，其它按填空），**第三列 = 题干**，**第四列及以后 = 答案**（多列即多空/多项）。

### Excel（.xlsx / .xls）—— 推荐
直接在 Excel/WPS 里按上面四列排版即可，题干里的 `$` 会被自动转成 `____` 空位。
一个文件可含多个题库（第一列不同题库名自动分成多个独立题库）。

### CSV（.csv，UTF-8）
一个 CSV 文件默认 = 一个题库（用文件名作题库名；若首列是题库名则按首列分组）。
表头可选（`知识类型,题干,答案,选项`）。示例：

```csv
题库名,知识类型,题干,答案,选项
党员应知应会,填空,“四个意识”是指什么？,政治意识｜大局意识｜核心意识｜看齐意识,
党员应知应会,填空,党支部委员会由$人组成,3至5｜7,
党员应知应会,单选,党的最高理想是什么？,实现共产主义,实现共产主义|全面建成小康社会|实现中华民族伟大复兴
```

- 填空题题干里的 `$` 符号表示空位，会被自动转成 `____`；答案列里多个空用 `｜` 分隔。
- 选择题若**不填选项**，App 会自动从**同一题库内**抽取干扰项生成 4 个选项。
- 导入时若遇到同名题库，会询问「覆盖」还是以「_副本」新建；在题库详情里「导入覆盖」可用文件整体替换该题库。

## 在手机上怎么用

1. 安装 APK 后打开，默认内置 1 个题库「党员应知应会」（共 53 题，全填空，含多空题），即你提供的 Excel 转换而来。
2. **练习 / 复习**：底部「练习」选**题库**与知识类型开始；「复习」按记忆曲线练待复习题（同样可指定题库）。
3. **管题库**：
   - 底部「题库」列表 → 每题库有「打开」「删除」；
   - 点「导入题库」→ 从手机文件管理器选 `.xlsx` / `.xls` / `.csv`（可一次建多个题库）；
   - 点开一个题库 → 「编辑题库」直接在表格里改（知识类型/题干/答案/选项），输入即自动保存；「+ 新增题目」加一行；「删」删单行；
   - 「导入覆盖」→ 用文件整体替换当前题库；「导出CSV」→ 写入本机存储（便于备份或换手机后再导入）；
   - 「删除题库」→ 彻底删除该题库及其全部题目与进度。
4. 「统计」页看每个题库独立的掌握率，以及全部题库的「一周掌握」总进度。

> 注：没有「新建空白题库」按钮——所有题库都通过导入文件建立（按你的要求）。

## 用 GitHub 自动出 APK

1. 在 GitHub 新建一个**空仓库**（如 `yky-android`）。
2. 本地进入本项目目录，关联并推送：
   ```bash
   git init
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git add -A
   git commit -m "init 应知应会安卓App"
   git branch -M main
   git push -u origin main
   ```
3. 进入仓库 **Actions** 标签页，找到 `Build APK` 工作流，等它跑完（约 3–5 分钟）。
4. 在任务页底部 **Artifacts** 下载 `yky-quiz-apk`（里面是 `app-debug.apk`）。
5. 把 APK 传到手机安装即可。**全程离线使用，无需联网。**

> 以后换题库：在手机 App 内「导入题库」直接加新题库（Excel/CSV 均可）；或改 `www/bank.js` 种子后重新 push 出包。

## 本地预览（电脑）

无需构建也能看效果：直接双击 `www/index.html`，或起个静态服务：

```bash
cd www && python3 -m http.server 8080   # 浏览器开 http://localhost:8080
```

## 技术说明

- 安卓端仅是一个 `WebView`，加载 `file:///android_asset/public/index.html`，开启 `DOM storage` 以持久化题库与进度。
- `<input type="file">` 已适配（`onShowFileChooser`），可在手机上选 Excel/CSV 导入；导出通过 JS 桥 `Android.saveCsv` 写本机存储（无需联网/权限）。
- 出包用的是 GitHub 托管的 Ubuntu runner + Android SDK（`setup-android`），产物为 **debug APK**（无需签名即可安装自用）。如需正式发布，可自行配置签名后再 `assembleRelease`。
